Sunset Platinum — an offline, static GTA VI trophy guide & tracker for PlayStation 5: all 55 official trophies with their official names, descriptions and grades, a checklist tracker with progress saved in the browser, full cited guides (Exophase for the official list, PSNProfiles for PSN-tracked targets), a 4-phase platinum roadmap, a missables list, a Next up planner and per-trophy notes. No network requests; dark and light themes. Where a place or step is not pinned down by the official description, the guide says so instead of inventing one.

## Run it

```sh
cd app && python3 -m http.server
```

Then open http://localhost:8000 in a browser.
