Sunset Platinum — an offline, static GTA VI trophy guide & tracker for PlayStation 5: all 55 official trophies with their official names, descriptions and grades, a checklist tracker with progress saved in the browser, a computed data audit strip (55/55 official entries verified, every guide step cited, claims with 2+ sources, source pages and sites, disputes and unconfirmed methods), full cited guides (Exophase for the official list, PSNProfiles for PSN-tracked targets, PowerPyx, GTA Zone, CryptoGames and quoted GTABase/TechWiser), a standalone Sources tab with the source table, the trophy × source matrix and what the sources agree on, differ on and leave undecided, a 5-stage platinum roadmap with a sourced platinum summary, a tiered missables list (1 possibly missable + 5 watch) with a Chapter 1–5/Post last-chance timeline, a Next up planner, and per-trophy notes. No network requests; dark and light themes; spoiler shield on by default. Where a place or step is not pinned down by a source, the guide says so instead of inventing one.

## Run it

```sh
cd app && python3 -m http.server
```

Then open http://localhost:8000 in a browser.
